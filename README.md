# DSA practice

A working archive of data-structure, algorithm and SQL problems I have solved while preparing for interviews and improving problem-solving fluency.

Most solutions are in Java, but the repository is not Java-only. It also contains C++, JavaScript, Python and SQL exercises. The problem folders are grouped by topic and generally keep a short problem note beside the solution.

## Browse by topic

The repository includes topic folders such as:

- Arrays and hashing
- Graphs and greedy algorithms
- Dynamic programming
- Trees, tries, heaps and stacks
- Linked lists and object-oriented programming

A larger set of platform-synced problems lives under Data Structures & Algorithms/. Each problem folder usually contains the original prompt notes and a solution file.

## Languages

Java is the main language used for the structured practice, with additional solutions in C++, JavaScript, Python and SQL.

These are individual practice solutions, not a packaged library or a single runnable application. Open a problem folder to see its implementation.
